# YouTube Clickbait Analyzer

Консольное приложение (CLI) для автоматизированного анализа метрик YouTube-каналов. Программа обрабатывает CSV-файлы с данными о видео и формирует аналитические отчеты.

## Основной функционал
* **Сводный анализ**: Чтение и объединение данных из нескольких CSV-файлов в единую структуру данных[.
* **Отчет `clickbait`**: Поиск видео с аномальными показателями — высоким CTR (>15%) и низким удержанием аудитории (<40%).
* **Гибкая сортировка**: Автоматическая сортировка результатов по убыванию кликабельности (CTR).
* **Валидация данных**: Встроенная проверка типов данных и структуры входящих CSV-файлов.

## Требования
* Python 3.11+
* Библиотеки: `tabulate` (для визуализации таблиц), `pytest` (для запуска тестов).

## Инструкция по запуску

Для работы приложения необходимо передать ключевое слово `--files`, пути к файлам и тип отчета через флаг `--report`.
