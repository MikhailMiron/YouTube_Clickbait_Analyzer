# YouTube Clickbait Analyzer

Консольное приложение (CLI) для автоматизированного анализа метрик YouTube-каналов. Программа обрабатывает CSV-файлы с данными о видео и формирует аналитические отчеты.

## Основной функционал
* [cite_start]**Сводный анализ**: Чтение и объединение данных из нескольких CSV-файлов в единую структуру данных[cite: 4, 15].
* [cite_start]**Отчет `clickbait`**: Поиск видео с аномальными показателями — высоким CTR (>15%) и низким удержанием аудитории (<40%)[cite: 5, 11, 12].
* [cite_start]**Гибкая сортировка**: Автоматическая сортировка результатов по убыванию кликабельности (CTR)[cite: 13, 30].
* [cite_start]**Валидация данных**: Встроенная проверка типов данных и структуры входящих CSV-файлов[cite: 53].

## Требования
* Python 3.11+
* Библиотеки: `tabulate` (для визуализации таблиц), `pytest` (для запуска тестов).
